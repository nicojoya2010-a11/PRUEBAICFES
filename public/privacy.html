Política de privacidad

Última actualización: 14 de mayo de 2026

Práctica ICFES es una plataforma educativa independiente para practicar competencias tipo Saber 11. No representa al ICFES ni utiliza preguntas oficiales.

Datos que se pueden guardar

La aplicación puede guardar nombre, usuario, rol, estado de aprobación, preguntas creadas por docentes y resultados de práctica. Estos datos se usan para iniciar sesión, mostrar el avance del estudiante, permitir la gestión docente y mantener el historial de actividades.

Servicios usados

La plataforma puede usar Firebase Authentication para el inicio de sesión, Cloud Firestore para guardar información académica y Firebase Hosting para publicar la versión web.

Modo offline

Algunas funciones pueden conservar datos en el dispositivo para permitir el uso sin conexión. Cuando vuelve internet, la aplicación intenta sincronizar los cambios pendientes.

Publicidad y recompensas

Si se activa monetización en el futuro, la aplicación podrá mostrar anuncios recompensados para desbloquear funciones visuales, como temas de color. Esa integración se realizará mediante proveedores compatibles con las políticas de Google Play.
